# Scraping Workstream

## Goal

Use Firecrawl to retrieve a small, explicit set of public pages and normalize them into the shared document contract.

## Checklist

- [ ] Implement one-page scrape.
- [ ] Implement bounded crawl if time permits.
- [ ] Capture URL, title, links, timestamp, and hash.
- [ ] Store crawl status.
- [ ] Add timeout and retry behavior.
- [ ] Add fixture fallback.
- [ ] Respect site rules and rate limits.
