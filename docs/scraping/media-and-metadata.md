# Media and Metadata

## Optional tools

- **ExifTool:** inspect metadata from public images and documents.
- **yt-dlp:** archive explicitly public media when permitted by the source and applicable terms.
- **OpenStreetMap/Nominatim:** interpret places already named in public material; do not use it to locate a person.

## Provenance requirements

- [ ] Save the original URL.
- [ ] Save capture time.
- [ ] Save content hash.
- [ ] Distinguish extracted metadata from model interpretation.
- [ ] Do not generate claims from metadata alone.
