# Archival Sources

These are optional extensions after the live Firecrawl path works.

## Wayback Machine CDX API

Use it to find older public versions of an explicitly supplied URL. Store the archived URL, capture timestamp, and original URL as separate source metadata.

## Common Crawl

Use it as a historical corpus for research or offline fixtures. Do not make it a live-demo dependency.

## Checklist

- [ ] Preserve archive timestamp.
- [ ] Link the archived page to its original URL.
- [ ] Mark archived material separately from live material.
- [ ] Avoid duplicate indexing of identical captures.
