# Screen Specification

## Landing

Establish the question and start the demo.

## Ingest

Accept public URLs and show crawl scope before starting.

## Processing

Show sources arriving, page counts, failures, and extracted themes.

## Report

Show claims, confidence, claim type, and source links.

## Reveal

Show excerpts, contradictions, unknowns, and the difference between observation and inference.

## Draft review

Show the AI-generated label, citations, editable text, and review-required export state.
