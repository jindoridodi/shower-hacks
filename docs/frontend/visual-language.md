# Visual Language

## Direction

Quiet, clinical, and slightly uncanny. Use generous whitespace, typographic scale, and evidence fragments as visual material.

## Rules

- Sources should feel inspectable, not hidden in footnotes.
- Inferences use a distinct visual treatment.
- Unknowns should be prominent rather than treated as errors.
- Avoid chat bubbles that imply a real person is speaking.
- Make the source ledger the visual signature of the project.
