# Evidence and Confidence

- **High:** the same fact appears on multiple attributable pages.
- **Medium:** one attributable public source supports the fact.
- **Low:** the result is inferred from weak or indirect signals.
- **Unknown:** the corpus does not support the claim.

## Display rules

- Never hide the source excerpt.
- Never convert low confidence into a factual sentence.
- Show conflicts instead of choosing silently.
- Use “the corpus suggests” for inferences.
