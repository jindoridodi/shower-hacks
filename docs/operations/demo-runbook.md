# Demo Runbook

## Before the demo

- [ ] Start API.
- [ ] Start frontend.
- [ ] Check `/api/health`.
- [ ] Confirm fixture data.
- [ ] Confirm prepared URLs.
- [ ] Close unrelated browser tabs.

## If Firecrawl fails

Switch to the fixture corpus and continue the same presentation. Do not improvise a different product path.

## If generation fails

Show the corpus and source ledger. The evidence view remains a complete part of the artwork.
