# Testing Checklist

## API

- [ ] Health endpoint works.
- [ ] Invalid URL returns a readable error.
- [ ] Crawl failure is persisted.
- [ ] Empty search returns no claims.
- [ ] Every claim has a source.

## Frontend

- [ ] Loading state works.
- [ ] Empty state works.
- [ ] Error state works.
- [ ] Evidence drawer opens.
- [ ] Draft review label is visible.

## Demo

- [ ] Clean restart works.
- [ ] Fixture fallback works.
- [ ] Demo completes in under two minutes.
