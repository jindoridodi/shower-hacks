# Local Setup

## Requirements

- Node.js 20+
- Python 3.11+
- SQLite 3 with FTS5
- Firecrawl API key
- LLM API key or Ollama

## Checklist

- [ ] Install frontend dependencies.
- [ ] Create a Python virtual environment.
- [ ] Copy `.env.example` to `.env`.
- [ ] Initialize SQLite.
- [ ] Seed fixtures.
- [ ] Start API.
- [ ] Start frontend.
- [ ] Open the health endpoint.
