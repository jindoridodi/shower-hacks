# Deployment

## Hackathon recommendation

Use one frontend deployment and one API deployment. Keep SQLite on the API host for the demo, or bundle a read-only fixture database with the deployment.

## Checklist

- [ ] Set production environment variables.
- [ ] Run schema initialization.
- [ ] Seed fixture data.
- [ ] Confirm Firecrawl connectivity.
- [ ] Confirm API CORS settings.
- [ ] Confirm frontend API URL.
- [ ] Run the demo from the deployed URL.
