# Demo Script

## Two-minute flow

1. Open the landing page: “How much can a machine know from a few pages?”
2. Paste two or three public URLs.
3. Start the crawl and show source cards arriving.
4. Open the corpus view and point out dates, links, and excerpts.
5. Generate a factual profile.
6. Click a claim to reveal its supporting source excerpt.
7. Open the uncertainty view and show conflicting or missing evidence.
8. Generate one AI-labeled communication draft requiring review.
9. End with: “Which parts belong to the person, and which belong to the archive?”

## Before presenting

- [ ] Prepared public URLs are available.
- [ ] Firecrawl credentials work.
- [ ] Fixture data is ready.
- [ ] API and frontend are running.
- [ ] One person drives the demo and one narrates.
