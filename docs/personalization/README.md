# Personalization Workstream

## Goal

Generate useful, source-grounded reports and reviewed communication drafts without voice imitation or invented material.

## Checklist

- [ ] Build factual profile prompt.
- [ ] Build uncertainty prompt.
- [ ] Attach citations to every claim.
- [ ] Reject unsupported claims.
- [ ] Add communication-draft mode.
- [ ] Label drafts AI-generated.
- [ ] Require manual review before export.

## Prohibited behavior

- No “write exactly like this person.”
- No fabricated memories or events.
- No automatic sending or posting.
