# Communication Drafts

Communication drafts are optional, source-linked drafts prepared for human review.

## Requirements

- Display “AI-generated draft.”
- Do not claim to be written by the target.
- Do not imitate the target’s voice.
- Use only supported public details.
- Include a source panel.
- Require explicit manual review before export.
- Do not send, post, or email from the application.

## MVP format

```json
{
  "label": "AI-generated draft — review before use",
  "recipient": "",
  "subject": "",
  "body": "",
  "source_ids": [],
  "review_required": true
}
```
